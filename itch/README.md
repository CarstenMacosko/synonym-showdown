# Putting Synonym Showdown on itch.io

Files in this folder:
- `synonym-showdown-itch.zip`: **upload this**. It contains `index.html`, which shows the live game from
  synonymshowdown.com (always up to date; online rooms work; sign-in is hidden because it can't work inside itch.io).
- `cover-630x500.png`: the cover image.
- `screenshot-*.png`: screenshots for the page.

## Steps
1. itch.io → your profile menu → **Upload new project**.
2. **Title:** Synonym Showdown. **Project URL:** e.g. `synonym-showdown`.
3. **Short description / tagline:** Name a synonym… or call a bluff! A free multiplayer word game.
4. **Classification:** Games. **Kind of project:** HTML.
5. **Release status:** Released. **Pricing:** No payments (or "Donate").
6. **Uploads:** upload `synonym-showdown-itch.zip` and tick **"This file will be played in the browser"**.
7. **Embed options:**
   - Viewport dimensions: **960 × 720**
   - Tick **Mobile friendly** (orientation: Default)
   - Tick **Fullscreen button**
   - Leave "Automatically start on page load" unticked (players tap to start; that also lets audio play)
8. **Details → Description:** paste the text below. **Genre:** Puzzle (or Educational).
9. **Tags:** word-game, multiplayer, party-game, educational, vocabulary, casual, hand-drawn, browser, local-multiplayer, bluffing
10. **Cover image:** `cover-630x500.png`. **Screenshots:** the three `screenshot-*.png` files.
11. **Visibility:** Public → **Save**.

## Description (paste into itch.io)

**Name a synonym… or call a bluff!**

Everyone gets the same starter word, like *happy* or *obstinate*. On your turn, name a synonym nobody has said yet before the timer runs out. Think the last player made one up? **Challenge them!** If it really is a synonym, the challenger is out; if not, the bluffer is. Last one standing wins.

**Ways to play**
- **Play Friends:** create a room and share the 4-letter code (2–6 players, no account needed)
- **Vs. Bots:** outwit computer players who bluff back
- **Pass & Play:** friends on one device
- **Score Attack, Survival and the Daily Word** for solo practice

**Features**
- 300 starter words and 27,000+ synonyms, graded from closest to distant
- After every game, see a map of the word's meanings and every synonym you missed
- Customize your doodle face with hats, glasses, colors and more
- Hand-drawn look, original music, works on phones and computers
- Family-friendly: no chat, just emoji reactions

For accounts, ratings and ranked 1v1 matches, play at **https://synonymshowdown.com**.
