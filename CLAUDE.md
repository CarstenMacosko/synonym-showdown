# Synonym Showdown: project context

A word-bluffing game (web first, iOS App Store later via Capacitor). Players take turns naming synonyms of a
starter word; the next player may challenge the previous word. Real synonym → challenger out; bluff → bluffer out.
See README.md for modes, file layout, and roadmap.

## Architecture rules
- `src/game/` is pure TypeScript rules: (state, action, now, rng) → new state. No DOM, timers, or Math.random inside.
  The future online server will reuse it as referee. Every rule change gets a test in `src/game/*.test.ts`.
- `src/ui/` is React. Hand-drawn look comes from `sketch.tsx` (Rough.js); keep new UI in that style.
- Synonym data: `src/game/data/words.json`, generated by the free pipeline in `tools/wordbank/`
  (`npm run words:download | words:candidates | words:grade | words:build`). Sources: Open English WordNet,
  Wiktionary (kaikki.org), Moby Thesaurus, SCOWL, GloVe; they vote, then `grade.ts` assigns closeness
  1 close / 2 solid / 3 distant and meanings. Hand fixes go in `tools/wordbank/overrides.json`, never in the JSON.
  Tier 3 is noisy; game ranges: Close = 1, Standard = 1–2 (default, ranked), Loose = 1–3. Never scrape thesaurus.com.
- Online server: `worker/` (Cloudflare Worker + D1 database `synonym-showdown` + Durable Objects `GameRoom`
  per room code and one `Matchmaker`). The server runs `src/game/engine.ts` as referee; clients never receive
  the synonym list during play. Accounts = username + password (PBKDF2, HttpOnly session cookie). Ranked = 1v1
  Glicko (`src/game/rating.ts`, start 1000 / RD 350). Solo runs are replayed server-side (`soloVerify.ts`) before
  points count. Cheat detector (`suspicion.ts`): per-session score 0–100 from volume, speed, timing regularity,
  typing speed (desktop only), pastes and rare words, plus a per-user running average (`users.cheat_score`);
  tags (`users.suspicious`) only on blatant or repeated evidence, never bans. Its simulation tests must keep
  passing (no simulated human tagged). Tagged players show "under review" and are hidden from the leaderboard.
- Fresh words: each device remembers the starter words it has seen (`src/ui/seenWords.ts`, localStorage
  `ss-seen`; a difficulty's cycle restarts once all its words were seen). `pickStarter` in words.ts picks the
  word the fewest players have seen; online rooms get each player's list in `hello` and add the game's words
  when it ends.
- End screens use `src/ui/RoundPages.tsx`: one page per starter word of the game (`allRounds(state)`; online
  via `ResultView.rounds`, Survival via `SoloState.history`), each with the words played + Disagree buttons
  and the full answer map.
- Friends lobby: guests can rename (`rename` message; duplicate names rejected, joiners get "Name 2").
- Avatars: `src/game/avatar.ts` (options + server-side sanitizing), drawn by `src/ui/Avatar.tsx`; stored in
  `users.avatar`, guests in localStorage. Profile page `src/ui/Profile.tsx`. Dev-only gallery at `/?gallery`.
  Some parts unlock with account points (`UNLOCK_POINTS` in avatar.ts: propeller 5, sunglasses 25, top hat 50,
  santa hat 75, crown 100, wizard 250, vampire teeth 300, halo 500, diamond shape 1k, monocle 5k, shiny texture
  10k). The editor lists them last under "Earned with points" (light green once earned). The server rejects saving
  a locked part and swaps out unearned ones (guests count as 0 points). Bots can wear anything.
- Music: synthesized in `src/ui/music.ts` from note data in `src/ui/musicTracks.ts`; one track per lobby
  (home, room, ranked, studio), silent during games.
- Admin: owner account `CarstenMAdmin` (is_admin). Admin page has reports, cheat watch, accounts.
  `npm run accounts | reports | flags | make-admin -- <name>`. Growth plan: `docs/growth-ideas.md`.
  "Disagree?" reports land in the D1 `reports` table.
- Deploying: pushing to `main` deploys via Cloudflare's GitHub build. Database schema changes need a new file in
  `worker/migrations/` applied with `npx wrangler d1 migrations apply synonym-showdown --remote`
  (wrangler is logged in on this Mac). Local full-stack dev: `npm run build && npx wrangler dev`.

## Product decisions (already made by the owner, don't re-ask)
- Style: skribbl.io-like: mostly white, pencil-drawn shapes, bouncy animations; for all ages, not kids-only.
- Only the directly previous word can be challenged. Random first player. Running out of time = eliminated.
- Word forms count as the same word (joyful = joyfully); no repeats.
- Spelling forgiveness is a lobby setting (strict / typos / sound-alike); ranked always uses strict.
- After a knockout with 3+ players: lobby chooses a new word or keeps the same one.
- Starter words have difficulty tiers (easy / medium / hard).
- Accounts: guest + optional sign-up. Friends: room codes/invite links, friends list, pass-and-play.
- Ranked: 1v1 Elo only. Chat: emotes/quick phrases only.
- Free for now; ads may be added later (between-game slots only, `src/ui/AdSlot.tsx`). Target Poki/CrazyGames/Coolmath.
- Planned stack: Supabase (accounts, DB, realtime) + Cloudflare Pages hosting + Capacitor for iOS.
